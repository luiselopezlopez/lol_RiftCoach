# Design Context

- Audience: a Spanish-speaking League of Legends beginner, learning on Windows while attention is mostly on the game.
- Primary action: understand one short educational observation, without replacing the player's decision.
- Confirmed tone: quiet, readable, minimally distracting. Independent window or second monitor, not an overlay.
- Structure: profile questionnaire/results, training session, connection and local diagnostics.
- Visual direction: Hextech theme inspired by the League client (`src/LoLCoach/Themes/Hextech.xaml`): blue-black surfaces with a faint honeycomb texture, gold frames and headings (#C8AA6E / #785A28), hextech cyan (#0AC8B9) for the main action, focus and live data, red (#E84057) for rivals. Display font Beaufort for LOL with Constantia fallback, body Spiegel with Segoe UI fallback, Bahnschrift for numbers. No marketing hero or nested panels.
- States: unconfigured, waiting for profile, simulation, provisional text, completed advice, expired, stopped, request limit, credential/network error, missing Spanish voice, live policy restriction.
- Accessibility: keyboard focus, stable advice region, wrapping text, labels in addition to color, DPI-aware layouts.
